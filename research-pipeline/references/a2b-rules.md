# A2B 分析流程（细则）

> A = 分析 / B = 沉淀 双轨，四阶段逐步递进。贯穿整个流程的工具。

| 阶段 | A（分析） | B（沉淀） |
|------|-----------|-----------|
| 1 | 观察所有失败实验的现象 | 现象归类，找出指向同一根因的现象群 |
| 2 | 对归类后现象不断追问深层原因 | 建立因果链，描述问题所在 |
| 3 | 替换有问题模块，验证是否有效 | 多个改动须独立互不影响 |
| 4 | 消融：逐个加模块、量化收益 | 验证改动是否符合阶段 2 的分析 |

## 1a–4b 细则

| 阶段 | a（分析） | b（沉淀） |
|------|-----------|-----------|
| 1 | 观察所有失败实验的现象 | 把现象归类，找出指向同一根因的现象群 |
| 2 | 对归类后现象不断追问更深原因 | 建立因果链，逐层描述问题所在 |
| 3 | 替换 2b 中找到的有问题模块，验证是否有效 | 多个改动必须独立互不影响 |
| 4 | 消融：逐个加模块，量化每个模块收益 | 再次验证改动是否符合阶段 2 的分析 |

## 回退规则

某阶段数据不理想 → 回退上一阶段重走；对上一阶段几乎完全了解后才进入下一阶段。

## 创新等级（a–d）与 a/b 级方法论

> 用小写 a–d，避免与可信度 A/B/C 字母冲突。

| 级 | 定义 |
|----|------|
| a | 提出问题并用新颖方案解决 |
| b | 用新颖方案解决已知问题 |
| c | 直接套用其他论文的方案 |
| d | 仅对已有论文微调 |

- **a 级路径**：现有系统做出意料之外的事 → 不断追踪验证该现象 → 发现全新问题。
- **b 级路径**：本领域问题在别的领域也存在 → 借鉴别的领域如何解决（A2B 跨域迁移，见阶段二）。
